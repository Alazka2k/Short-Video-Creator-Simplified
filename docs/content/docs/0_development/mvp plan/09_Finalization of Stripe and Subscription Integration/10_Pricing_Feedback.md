# Narravid Pricing Page - UX/UI Design Feedback & Improvements

## Feedback Round 1

### Overall Assessment

**Areas for Improvement:**

- Visual balance and emphasis could be optimized
- Some UX patterns could better guide user decision-making
- Mobile responsiveness and accessibility considerations
- Trust signals and conversion optimization opportunities

### Detailed UX/UI Analysis

#### 1. Visual Hierarchy & Emphasis

##### **Issues Identified:**
- **Yearly" selection**: For yearly we only have three right now (because the free tier, which is only one in the database is shown in the monthly tier). Either we show the Free Tier Plan also in the Yearly selection, or we need to center if we only show three plans in the yearly.
- **Most Popular" badge placement**: Currently on Creator Tier but not visually prominent enough
- **Price emphasis**: Monthly prices blend in, yearly savings not prominent enough. Show also the monthly price in the yearly selection to emphasize the savings potential.
- **Feature lists**: All features have equal visual weight - no prioritization

##### **Recommended Improvements:**
- **Yearly selection**: Either we show the Free Tier Plan also in the Yearly selection, or we need to center if we only show three plans in the yearly. Depending what best practice is.
- **Hover Effect for each tier**: Add a hover effect for each tier to make it more interactive.
- **Price typography**: Larger font for main price, smaller for billing period
- **Feature highlighting**: Bold or color-code the most important 2-3 features per tier.

#### 2. Layout & Spacing

##### 🔴 **Issues Identified:**
- **Tier card heights**: Inconsistent due to varying feature count

##### ✅ **Recommended Improvements:**
- **Equal card heights**: All tiers have now the same amount of features defined in the copywriting document. Nevertheless all cards need to have the same heigth and width to look consistent.

#### 3. Interactive Elements & Micro-interactions

##### 🔴 **Missing Opportunities:**
- **Static cards**: No hover effects or interactive feedbacky

##### ✅ **Recommended Improvements:**
- **Card hover effects**: Subtle lift, glow, or border highlight on hover
- **Popular badge**: Improve the visual prominence of the most popular tier.

#### 4. Information Architecture

##### 🔴 **Issues Identified:**
- **Feature overload**: Too many features make comparison difficult
- **Token explanation**: Token system may confuse new users

##### ✅ **Recommended Improvements:**
- **Feature categorization**: Features are reduced and 2-3 features are highlighted.
- **Token explanation**: The token explanation is now in the FAQ section.
