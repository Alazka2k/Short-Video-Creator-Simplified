# Brand Guidelines

## Overview

These guidelines ensure consistency in design, tone, and experience across all touchpoints for Narravid.

---

## 4.1 Visual Identity

- **Logo:** Modern, gradient-based, adaptable for dark/light backgrounds
  - Primary logo: Full color version for standard use
  - Monochrome version: For limited color applications
  - Icon only: For favicons and small applications
  - Minimum size: 24px height for digital, 10mm for print
  - Clear space: Maintain space equal to 'N' height around the logo

- **Colors:**  
  - Primary: Vibrant purple (#B24BF3)  
  - Accent: Violet (#9747FF)  
  - Secondary: Off-white (#FAFAFA), Near-black (#0A0A0C)
  - UI accents: Success green (#4CAF50), Warning amber (#FFC107), Error red (#F44336)

- **Typography:**  
  - Headlines: Bold, expressive sans-serif (e.g. Space Grotesk, Spline Sans)
  - Body: Clean sans-serif (Inter)
  - Code: Monospace for technical elements (Fira Code)

- **Imagery:**  
  - Use cinematic, AI-inspired, and creative visuals
  - Showcase real examples and abstract backgrounds
  - Maintain high-contrast for readability
  - Utilize gradients to represent AI capabilities

- **UI Elements:**
  - Rounded corners (8px radius)
  - Subtle shadows for elevation
  - Consistent icon style (rounded line icons)
  - Consistent button styles and states

---

## 4.2 Tone & Voice

- Empowering, not intimidating
- Futuristic, but accessible
- Clear, concise, and benefit-driven
- Technical when necessary, but always explained
- Enthusiastic about possibilities without overselling
- Respectful of creator expertise

### Writing Guidelines:

- Use active voice
- Keep sentences short and direct
- Balance technical accuracy with accessibility
- Address the user directly ("you" instead of "users")
- Highlight benefits before features

---

## 4.3 UI/UX Principles

- Mobile-first, responsive layouts
- Use animated gradients and glassmorphism sparingly
- Prioritize clarity, minimalism, and delightful micro-interactions
- Progressive disclosure for complex features
- Consistent navigation and information architecture
- Meaningful loading states and feedback

### AI Visualization Principles:

- Represent AI processes with flowing gradients
- Use animation to indicate processing
- Show confidence scores visually when relevant
- Provide visual differentiation between AI-generated and user-created content
- Use interface metaphors that bridge traditional video editing and AI concepts

---

## 4.4 Do's & Don'ts

| Do                                 | Don't                                 |
|-------------------------------------|---------------------------------------|
| Use the official gradient palette   | Use random or clashing colors         |
| Keep copy direct and positive       | Be overly technical or negative       |
| Show real user examples             | Use generic stock photos              |

---

*Update guidelines as brand evolves or new platforms are added.*
